# Ask Then Do It codex 1.4.1

Use the Codex Plugin to guide requirements, implementation, and Review. Start with `$ask-then-do-it`.

Keep the complete `ask-then-do-it/` folder for ZIP fallback. Follow the linked guide to finish installation through a local Marketplace, then open a new Codex task before using the example below.

[guide](https://github.com/Mysterio1001/Ask-Then-Do-It/blob/v1.4.1/docs/guides/codex.en.md#zip)

## Getting started

```text
$ask-then-do-it Help me build a booking website. Please use English.
```

**Full** keeps requirements, specification, and a Ticket Plan, with three approvals before implementation. **Lite** suits clearly scoped changes and uses a short Change Brief with one approval.

[beginner guide](https://github.com/Mysterio1001/Ask-Then-Do-It/blob/v1.4.1/docs/guides/getting-started-simple.en.md)

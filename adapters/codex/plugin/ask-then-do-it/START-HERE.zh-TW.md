# Ask Then Do It codex 1.4.0

使用 Codex Plugin 引導需求、實作與 Review。一般從 `$ask-then-do-it` 開始。

ZIP 備援請保留完整 `ask-then-do-it/` 資料夾，先依下方使用說明完成本機 Marketplace 安裝；完成後開啟新的 Codex 任務，再使用下方範例。

[使用說明](https://github.com/Mysterio1001/Ask-Then-Do-It/blob/v1.4.0/docs/guides/codex.zh-TW.md#zip)

## 開始使用

```text
$ask-then-do-it 幫我建立一個預約網站，請使用繁體中文。
```

**Full** 適合需要需求、規格與工作規劃紀錄的工作，實作前有三個核准點。**Lite** 適合範圍清楚的改動，使用簡短變更摘要與一次核准。

[初學者流程](https://github.com/Mysterio1001/Ask-Then-Do-It/blob/v1.4.0/docs/guides/getting-started-simple.zh-TW.md)

# Ask Then Do It codex 1.4.0

Codex Plugin で要件確認から実装、Review まで進めます。通常は `$ask-then-do-it` から始めます。

ZIP フォールバックでは完全な `ask-then-do-it/` を保持し、下のガイドに従ってローカル Marketplace でのインストールを完了してください。その後、新しい Codex タスクで以下の例を使います。

[使用ガイド](https://github.com/Mysterio1001/Ask-Then-Do-It/blob/v1.4.0/docs/guides/codex.ja.md#zip)

## 使い始める

```text
$ask-then-do-it 予約サイトの開発を手伝ってください。日本語で進めてください。
```

**Full** は要件、仕様、Ticket 計画を保存し、実装前に三つの承認を求めます。**Lite** は範囲が明確な変更向けで、短い変更概要と一度の承認を使います。

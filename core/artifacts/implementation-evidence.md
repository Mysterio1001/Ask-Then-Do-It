# Implementation Evidence Artifact

## Capability requirement

Completed Implementation Evidence requires `tools`.

## Required content

- Approved ticket and upstream artifact references.
- Changed files or ownership areas.
- Expected red command, result, and failure reason.
- Focused green command and result.
- Refactoring performed.
- Broader verification commands and raw outcomes.
- Test-first exceptions and alternative verification, if any.
- Residual risks and incomplete checks.
- Final ticket status.

Unexecuted proposals MUST use a different label and MUST NOT be represented as Implementation Evidence.

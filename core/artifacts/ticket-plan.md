# Ticket Plan Artifact

## Required content

- Link or reference to the approved Specification.
- Dependency order and proposed parallel groups.
- One or more vertically testable tickets.

Each ticket includes outcome, acceptance criteria covered, scope, dependencies, ownership areas, test-first approach, verification, completion criteria, and parallel-safety reasoning.

Status starts as `Draft` and becomes `Approved` only with explicit approval evidence. The approved artifact hands eligible tickets to implementation.

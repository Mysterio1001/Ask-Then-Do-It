# Draft Working Notes Artifact

## Purpose

Retain provisional discoveries during documented requirement interrogation without representing them as approved project facts.

## Required content

- The shared artifact envelope with `status` fixed to `Draft`.
- The current requirement decision map and its source evidence.
- Entries labeled `proposed`, `confirmed`, or `unresolved`.
- The next unanswered high-impact decision.
- A handoff back to documented requirement interrogation.

A `confirmed` entry records that the user confirmed the statement during interrogation. It MUST NOT become formal project knowledge until the related Requirement Decision Record and disclosed Knowledge Base changes receive explicit approval (`KB-DRAFT-001`).

Draft Working Notes are supporting workflow state and do not introduce another approval gate.

# Direct Implementation Evidence Artifact

## Capability requirement

Completed Direct Implementation Evidence requires `tools`.

## Required content

- Approved Specification, Ticket Plan, Ticket, and `direct` mode references.
- Changed files or ownership areas.
- Raw commands and outcomes for permitted non-test verification.
- The exact disclosure `tests: skipped-by-user`.
- Untested areas and unavailable behavioral evidence.
- External CI, hosting, or release-system test constraints and delivery blocks, when present.
- Scope-drift inspection result.
- Residual risks and incomplete checks.
- Final Ticket status and Review handoff.

The artifact MUST NOT contain Red, Green, passing-test, test-verified, or TDD-complete claims. Unexecuted proposals MUST use a different label and MUST NOT be represented as Direct Implementation Evidence.

# Direct Implementation Evidence Artifact

## Capability requirement

Completed Direct Implementation Evidence requires `tools`.

## Required content

- Approved Specification, Ticket Plan, Ticket, and `direct` mode references.
- Changed files or ownership areas.
- Approved test choice and raw commands and outcomes for permitted verification.
- For `Run existing tests only`, record the actual tests and their outcomes or why they were unavailable. For the skip choice and legacy direct approvals, use the exact disclosure `tests: skipped-by-user`.
- Untested areas and unavailable behavioral evidence.
- External CI, hosting, or release-system test constraints and delivery blocks, when present.
- Scope-drift inspection result.
- Residual risks and incomplete checks.
- Final Ticket status and Review handoff.

Only observed existing-test outcomes support specific pass/fail claims. Direct evidence never proves TDD. Unexecuted proposals MUST use a different label and MUST NOT be represented as Direct Implementation Evidence.

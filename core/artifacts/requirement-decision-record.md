# Requirement Decision Record

## Required content

- Problem and desired outcome.
- Users and success signals.
- Scope and non-goals.
- Primary behavior and user flow.
- Edge cases and failure behavior.
- Data, dependencies, security, privacy, and operational constraints.
- Acceptance criteria.
- Confirmed decisions, assumptions, and deferred decisions.
- Explicit consensus evidence.

Status remains `Draft` until requirement consensus is explicitly confirmed. The approved record hands off to Specification authoring.

When documented requirement interrogation is active, present the record with a Knowledge Base Change Summary. One explicit approval may approve both only when the complete proposed additions, modifications, and removals are visible in the same request.

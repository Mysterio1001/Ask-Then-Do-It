# Ask Then Do It generic 1.4.0

適合 Gemini 或其他能接收長文字的 AI。貼上工作流即可使用，不需安裝 Plugin。

每個新對話都先貼上 `generic-workflow.md` **全文**，再說明需求，例如：

[使用說明](https://github.com/Mysterio1001/Ask-Then-Do-It/blob/v1.4.0/docs/guides/generic.zh-TW.md)

## 開始使用

```text
幫我建立一個預約網站，請使用繁體中文。
```

**Full** 適合需要需求、規格與工作規劃紀錄的工作，實作前有三個核准點。**Lite** 適合範圍清楚的改動，使用簡短變更摘要與一次核准。

[初學者流程](https://github.com/Mysterio1001/Ask-Then-Do-It/blob/v1.4.0/docs/guides/getting-started-simple.zh-TW.md)

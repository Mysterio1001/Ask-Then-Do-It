# Ask Then Do It generic 1.4.2

適合 Claude Desktop Skills，以及其他能接收長文字的 AI。請在 Claude Desktop 的 Skills 功能上傳此 ZIP；入口 `SKILL.md` 位於 ZIP 內套件資料夾的根目錄。安全掃描完成後，啟用 Skill 並指定使用 Ask Then Do It。

只有文字對話能力的服務，每個新對話都先貼上 `SKILL.md` **全文**，再說明需求，例如：

[使用說明](https://github.com/Mysterio1001/Ask-Then-Do-It/blob/v1.4.2/docs/guides/generic.zh-TW.md)

## 開始使用

```text
請使用 Ask Then Do It 協助規劃一個預約網站，請使用繁體中文。
```

**Full** 適合需要需求、規格與工作規劃紀錄的工作，實作前有三個核准點。**Lite** 適合範圍清楚的改動，使用簡短變更摘要與一次核准。

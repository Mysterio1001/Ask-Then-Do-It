# Ask Then Do It Generic 1.0.1 使用ガイド

このパッケージは、Gemini など長い文章を受け取れる AI サービス向けです。ワークフローを会話に貼り付けるだけで、要件の確認から始められます。

このプロジェクトは Matt Pocock の skills repository から着想を得た独立プロジェクトであり、Matt Pocock との提携関係や同氏による推奨を示すものではありません。ライセンスと出典については、パッケージ内の `LICENSE` と `THIRD_PARTY_NOTICES.md` を参照してください。

## 新しい会話の始め方

1. `generic-workflow.md` を開きます。
2. 全文をコピーして、新しい AI の会話に貼り付けます。
3. 同じメッセージか次のメッセージで、要望と使用したい言語を伝えます。
4. 以前の作業を続ける場合は、保存した重要な文書も貼り付けます。

AI の最初の有効な返答では、現在の段階が短く示され、その後に推奨回答と主なトレードオフを含む最初の要件質問が一つ提示されます。

## 進め方

- 一度に一つの重要な質問が行われます。
- 要件、仕様、Ticket 計画には、それぞれ明確な承認が必要です。
- Ticket 計画を承認してから実装段階に進みます。
- Review では、提示された情報から確認できることと確認できないことが区別されます。

## できることの範囲

Generic 版は会話の中でワークフローを案内します。それ自体がファイルを編集したりテストを実行したりすることはできません。利用する AI サービスにファイル操作やツール機能がある場合は、実際に提供されている機能の範囲で使用してください。

## 進捗を保存する

AI が作成した要件記録、仕様、Ticket 計画、Review、その他の重要な文書を保存してください。

新しい会話では毎回 `generic-workflow.md` をもう一度貼り付けます。以前の作業を続ける場合は、保存した文書と新しい要望も貼り付けてください。AI は最初の未完了段階から続けます。

## 詳細な使い方

`prompts/` フォルダーには、段階別の 9 個のモジュールがあります。流れに慣れたら、必要なモジュールを直接選べます。通常は `generic-workflow.md` を使用してください。

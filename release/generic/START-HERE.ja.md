# Ask Then Do It generic 1.4.0

Gemini など、長いテキストを受け取れる AI 向けです。ワークフローを貼り付けるだけで、Plugin のインストールは不要です。

新しい会話ごとに `generic-workflow.md` の**全文**を貼り付け、その後に依頼を伝えます。例：

[使用ガイド](https://github.com/Mysterio1001/Ask-Then-Do-It/blob/v1.4.0/docs/guides/generic.ja.md)

## 使い始める

```text
予約サイトの開発を手伝ってください。日本語で進めてください。
```

**Full** は要件、仕様、Ticket 計画を保存し、実装前に三つの承認を求めます。**Lite** は範囲が明確な変更向けで、短い変更概要と一度の承認を使います。

[初心者向けガイド](https://github.com/Mysterio1001/Ask-Then-Do-It/blob/v1.4.0/docs/guides/getting-started-simple.ja.md)

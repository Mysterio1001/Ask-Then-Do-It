# Ask Then Do It generic 1.4.1

For Claude Desktop Skills and other AI services that accept long text. Upload this ZIP as a Skill in Claude Desktop; `SKILL.md` is at the root of the package folder inside the ZIP. After the security scan, enable the Skill and ask to use Ask Then Do It.

For a text-only host, paste the **entire** `SKILL.md` into every new conversation, then describe your task, for example:

[guide](https://github.com/Mysterio1001/Ask-Then-Do-It/blob/v1.4.1/docs/guides/generic.en.md)

## Getting started

```text
Use Ask Then Do It to help me plan a booking website. Please use English.
```

**Full** keeps requirements, specification, and a Ticket Plan, with three approvals before implementation. **Lite** suits clearly scoped changes and uses a short Change Brief with one approval.

[beginner guide](https://github.com/Mysterio1001/Ask-Then-Do-It/blob/v1.4.1/docs/guides/getting-started-simple.en.md)
